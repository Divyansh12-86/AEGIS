Each trajectory plot contains 8 synchronized panels formatted with publication-quality typography and proportions:
1. Sensor trajectories (first 6 normalized channels, mean per window)
2. VQ discrete operational event sequence ($v_t \in \mathcal{V}$)
3. HSMM state posterior belief heatmap ($p_t(m)$) with aligned colorbar
4. Viterbi inferred state sequence vs Ground Truth health state (step plots)
5. State age (elapsed dwell $\tau_t$ in active state with shaded fill)
6. Predicted RUL vs True RUL with shaded error band and trajectory RMSE annotation
7. Health state regime transitions (true onsets vs inferred boundaries)
8. VQ operational event change points

## Recommended Figures for Schneider Presentation

### 1. Ablation Bar Chart (Primary Result)
**Data**: `ablation_report_DS01.json` + `ablation_report_DS02.json`
**Plot**: Grouped bar chart — Arm vs RMSE (DS01/DS02 side by side)
**Bars**: A(24.2/25.4), B(22.4/24.7), C(23.8/25.1), D(23.4/24.4), **E(19.8/17.3)**, E2(24.0/19.9), F(22.9/24.4), CNN(34.0/28.9), LSTM(38.8/41.2)
**Annotation**: "E wins by 10+ RMSE vs CNN/LSTM; explicit duration gives 15% gain"

### 2. MIMII AUROC Ranking
**Data**: `mimii_fan_id_XX_3seeds.json` (4 IDs × 7 arms)
**Plot**: Horizontal bar chart, arms sorted by macro AUROC
**Bars**: A1(0.628), AE(0.596), Pooled(0.591), HSMM(0.520), CBM(0.389), Markov(0.511), GV(0.146)
**Annotation**: "Continuous HSMM (A1) beats discrete primary by 0.07 AUROC; Markov collapses; GrammarViz anti-correlated"

### 3. Degradation Trajectory (Figure 3)
**File**: `DS01_DS01_u2_trajectory.png` (or DS01_u9 for failure case)
**Caption**: "EGPM sees degradation: sensors → discrete events → HSMM states → RUL prediction tracking true RUL. State transitions align with health transitions (lag 0-1 windows)."

### 4. Faithfulness Masking
**Data**: `run_faithfulness.py` output
**Plot**: Bar chart — Score reduction per unit (DS01_u2: 0.18, 0.72; DS02_u2: 0.33, 0.22)
**Annotation**: "Masking top-3 scoring windows reduces anomaly score by 6-27% — explanations are faithful"

### 5. Dwell Features Win (RUL Readout)
**Data**: `run_rul_readout_study.py` output
**Plot**: Grouped bar — Feature set vs RMSE (DS01: full=27.1, post=27.1, dwell=23.5, PT=29.5; DS02: full=23.3, post=25.6, dwell=19.9, PT=310)
**Annotation**: "Dwell features alone beat full features on DS02; phase-type catastrophic on DS02"
